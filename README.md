# Escape to Lostman's River — companion site

The interactive companion to the novel, built as *the Guidebook*: Matt's dad's fishing guidebook with the blank pages filled in. Static Astro site; the printed book's QR codes point at `/ch/<n>/`.

## Run it

```bash
npm install
npm run dev        # http://localhost:4321 (trims sketches, then starts Astro)
npm run build      # validate data → trim sketches → build to dist/
npm run preview    # serve dist/
npm run linkcheck  # after a build: every internal link resolves, every <img> has alt
npm run qr         # regenerate the 25 print QR codes into qr/ (set the domain first)
```

Node 22 or newer.

## Where things live

```
SPEC.md               the brief: scope, pages, stack, QR contract, acceptance criteria
CLAUDE.md             conventions for coding sessions
site.config.mjs       domain, buy link, email/analytics providers, pull-quotes  ← author edits this
data/*.json           all content, cross-referenced by id (validated at build)
assets/sketches/      Linda McKillop's original scans — never modified
assets/photos/        the "For Dad" photo
src/assets/sketches/  derived, trimmed sketches (gitignored; regenerated by npm run trim)
src/lib/data.ts       typed access to the JSON
src/lib/url.ts        base-path-aware url() helper — always use it for internal links
src/pages/            one file per route; ch/[n].astro is the QR landing page
scripts/              validate, trim-sketches, make-qr, linkcheck
docs/                 DESIGN.md, OPEN-ITEMS.md (things only the author can decide), CREDITS.md
qr/                   generated QR SVGs + contact sheet (commit after the domain is final)
```

## Routes

| Route | Page |
|---|---|
| `/` | Home |
| `/ch/1/` … `/ch/23/` | Chapter pages (QR targets, never rename) |
| `/map/` | The Chart (Leaflet, chapter stepper, hand-drawn overlay). `#ch7` selects a chapter, `#place-id` opens a place. |
| `/fish/`, `/crew/`, `/critters/`, `/boats/` (+ `/<id>/`) | Field-guide sections |
| `/tackle/` | Tackle Box with rig diagram and tide explainer |
| `/list/` | Matt's List (localStorage) + the reader's own list |
| `/sketchbook/` | All sketches, with lightbox |
| `/about/`, `/credits/` | About the book, authors, next summer, sign-up; sources |

## Deploying

Push to `main`. `.github/workflows/deploy.yml` builds and publishes to GitHub Pages.

- **Without a custom domain** the workflow builds under `/<repo-name>/` automatically. Fine for previewing; the QR paths will not match yet.
- **With a custom domain:** set repository variables `SITE_URL=https://yourdomain` and `BASE_PATH=/`, add `public/CNAME` containing the bare domain, enable "Enforce HTTPS" in Pages settings, then `npm run qr` and commit `qr/`.

## Adding content

Everything on the site comes from `data/`. To add a fish, character, place or sketch, edit the JSON (ids are kebab-case, chapters are 1–23) and run `npm run validate`. Components never hard-code content.
