## Notes

- Amazon does not allow clickable off-Amazon links in a description, but a plain domain name in the text is allowed and common. Write it as `lostmansriver.com`, not as a link.
- The Experience is a paid product sold on the author's site. Mentioning it on Amazon is allowed; pricing it there is not necessary and dates quickly, so the description names it without a price.
- Do not put the Amazon Associates link anywhere in the book or the listing; Associates forbids affiliate links in print, PDFs and email.
