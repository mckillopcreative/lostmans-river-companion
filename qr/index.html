Escape to Lostman's River — QR codes (https://lostmansriver.com)

Each code is an SVG in this folder (plain) and a PNG in framed/ (inside the hand-drawn frame). Print the plain code at 19 mm (0.75 in) or larger with the URL beneath; the framed version works at 30 mm and up. Chapter paths are a print contract and never change. Scan a printed proof before the press run.
